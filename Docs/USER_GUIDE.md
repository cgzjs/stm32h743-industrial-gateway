# 屏幕与上位机操作说明

## 打开电脑上位机

当前可直接运行的是Qt/PyQt上位机，无需启动CubeIDE或Qt Creator。在资源管理器打开工程根目录，双击 **打开上位机.cmd**。也可在VS Code执行任务 **Gateway: Open PC manager (real board)**，或者运行：

```powershell
cd <你的工程目录>
python PC_Tools/Qt_Gateway_Manager/main.py
```

窗口右上角输入开发板IP，默认192.168.10.50，再点“连接”。ST-Link负责烧录和调试；这个上位机通过开发板RJ45以太网通信，监控端口502、维护端口5001，程序会自行使用这些端口，无需选择COM串口。

**打开上位机演示.cmd** 或VS Code的 **Gateway: Qt demo** 启动本机仿真，标题显示“演示数据”，IP为127.0.0.1。演示中的温湿度和电机是模拟数据，不能据此判断实板是否连接成功。

## 第一次联网

开发板默认192.168.10.50/24，电脑连接开发板的网卡需要设置到同一网段。修改正在上网的网卡会影响当前网络，请先安排好上网连接。

方便的独立联调方法是：先让电脑通过Wi-Fi保持上网，再用网线将电脑有线网口直连开发板RJ45。只给这条直连的以太网网卡设置：

| 项目 | 值 |
|---|---|
| 电脑有线网卡IPv4 | 192.168.10.2 |
| 子网掩码 | 255.255.255.0 |
| 直连网卡默认网关/DNS | 留空 |
| 开发板地址 | 192.168.10.50 |

Windows可按Win+R，输入 `ncpa.cpl`，找到实际连接开发板的“以太网”→属性→Internet协议版本4(TCP/IPv4)→属性，设置上述地址。记录原设置，联调结束需要接回路由器时恢复原来的自动获取。不要更改Wi-Fi的IP。若没有可用Wi-Fi或第二网卡，直连会临时占用当前上网网口，需要先安排好网络再改。

插好网线、等待板卡启动后，上位机输入192.168.10.50并连接。也可在终端检查端口：

```powershell
Test-NetConnection 192.168.10.50 -Port 502
```

`TcpTestSucceeded=True`说明监控TCP端口可达。屏幕Ethernet=UP表示物理链路建立；电脑网卡按上表配置IP后连接。

## 开发板屏幕四个页面

| 页签 | 内容与操作 |
|---|---|
| Monitor | `T`是温度℃，`RH`是相对湿度%；Motor显示实际转速rpm、电流mA；红色曲线温度、蓝色曲线湿度。OFFLINE表示设备离线，界面保留最近一次有效读数。 |
| Motor | 上方数字是目标速度0..600 rpm，`−/+`调整；`Reverse`选择方向；修改后点`Run`下发速度命令；`Stop`停止并禁用驱动。下方数字是绝对位置脉冲，`−/+`每次调整51200，点`Move`下发绝对位置命令。 |
| System | FW是运行版本；Ethernet UP/DOWN是物理网线链路；SD READY/MISSING表示日志存储是否可用，MISSING也可能是挂载失败；Alarms是十六进制报警掩码；OTA是下载进度；Motor lease=2 seconds表示控制心跳租约。`Touch`重新进入三点触摸校准。 |
| Alarms | 最近32次报警掩码变化，最新在上。时间为板卡启动后的秒数，0表示当时报警清除。SD卡另有报警CSV日志。 |

三点校准按屏幕上实际显示的＋中心，逐个按稳并松开，不是按物理边角。触摸失准无法点击Touch时，使用 [ST-Link重校准入口](TOUCH_RECOVERY.md)。

## 上位机四个页面

### 实时监控

连接后约每500ms读取一次温湿度、电机转速/电流/位置和状态，绘制约90秒趋势。显示“离线”时先排查接线、跳线、设备供电与协议参数。底部状态包含版本、运行秒数、位置、驱动状态、使能、最近控制来源、本地/远程和SD状态；使能字段显示网关记录的电机控制状态。

空载初试可设20~50 rpm，点“速度运行”，确认实际反馈，再点“停止/禁用”。“反向”在下发运行/移动命令时生效。上位机运行控制期间自动发送心跳；失去有效控制心跳超过2s，网关会发送禁用命令。电机停止命令通过CAN总线发送。

“绝对位置脉冲”是相对驱动器零点的目标位置，51200脉冲对应一圈；当前就在这个目标时，再点同一目标不会再额外转一圈。反向选择相应方向的目标幅度。联调时一次使用一个控制端，避免屏幕和PC互相改目标。

“导出本次监控CSV”导出上位机当前保留的记录，最多10000条，不是读取SD历史文件。

### 设备参数

先点“读取参数”，再修改；电机停止且无待安装升级时点“保存参数到Flash”。IP保存后下次重启生效，重连时使用新IP。传感器地址、波特率、读功能码、连续寄存器起始地址、顺序和乘除倍率按设备协议配置。

默认值为地址1、9600、8N1、FC3、起始0、温度在前、湿度在后、换算乘1。换算后统一为0.1℃/0.1%RH：原始数据已是0.1单位选乘1，若原始是0.01单位选除10。PC保存传感器参数时保留触摸校准系数。

### 固件升级

先完成监控与低速控制联调，再测试升级。选择正常候选 `build/Upgrade/Gateway.bin`，同目录须有匹配的`Gateway.json`，点“上传、校验并重启”。需要版本高于当前已确认版本，驱动器已确认禁用；安装并持续健康后新版本才确认，未确认复位会回滚。“中断下载”取消尚未完成的传输，重传从0开始。

不选择Bootloader作为升级文件。`build/Failure`是故意无法正常启动的回滚测试包，日常使用不要选择它。

### 故障记录

显示本次PC会话观察到的报警变化，不是自动下载SD上的历史日志。报警位可以同时出现：

| 十六进制位 | 含义 |
|---|---|
| 0x01 | 温湿度传感器离线/读数无效 |
| 0x02 | CAN电机反馈离线/无效 |
| 0x04 | Ethernet物理链路断开 |
| 0x08 | SD卡或文件系统/日志异常 |
| 0x10 | 电机报告故障 |
| 0x20 | 控制心跳超时或触发保护停机 |
| 0x40 | 外部Flash初始化异常 |

例如0x03=温湿度与CAN同时异常，0x0C=网线与SD异常，0x00=没有这些报警。电机状态数值0空闲、1到位完成、2运行、3过载、4堵转、5欠压。
